# Claude 103: Agents, Integrations, and Advanced Workflows
Learn how to use one of the most powerful AI tools

![Claude 103](Claude_103.avif)

## Details
Claude 103 moves beyond everyday prompting and workspace organization into more advanced AI workflows using agents, sub-agents, and MCP.
In this session, we’ll explore how Claude can coordinate more complex tasks, delegate work across specialized agents, connect to external tools and data sources, and support richer development and automation scenarios.

You’ll learn:
- What AI agents are and how Claude can use agentic workflows
- How sub-agents can divide complex work into specialized tasks
- How agents can coordinate, delegate, and combine results
- What the Model Context Protocol (MCP) is and why it matters
- How MCP connects Claude to tools, APIs, data sources, and external systems
- Practical tips, tricks, shortcuts, and prompting techniques

## Who Should Attend
- Completed Claude 101 and 102? Continue into Claude’s more advanced capabilities.
- Developers, architects, IT professionals, and technical users? Learn how Claude can interact with tools, systems, and specialized agents.
- Already comfortable with Claude? Discover advanced patterns that can improve automation, delegation, and productivity.

No previous experience with Claude is required.
