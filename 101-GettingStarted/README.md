# Claude 101: Getting Started with Anthropic’s AI Assistant
Learn how to use one of the most powerful AI tools

![Claude 101](Claude_101.avif)

## Details
Claude is an AI assistant from Anthropic designed to help with writing, research, analysis, coding, and everyday problem-solving.
In this session, we’ll focus on the essentials: what Claude is and how to use it effectively. We’ll also walk through practical examples so you can see how Claude can be used in real-world scenarios.
You’ll learn:

What Claude is and how it fits into the generative AI landscape
- The basic differences between Claude models
- How to write better prompts and provide useful context
- How to work with documents and files
- How Claude can help with writing, research, analysis, and coding
- Practical tips and best practices for getting better results

## Who Should Attend
New to Claude? Learn the fundamentals and see what it can do.
Developers, IT professionals, and business users? Get practical examples you can start using right away.

No previous experience with Claude is required.
