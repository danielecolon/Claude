# Claude 102: Personalization and Workspace
Learn how to use one of the most powerful AI tools

![Claude 102](Claude_102.avif)

## Details
Claude 102 builds on the fundamentals covered in Claude 101 and focuses on configuring Claude for more effective, repeatable, and personalized workflows.
In this session, we’ll explore how Claude’s settings, profile, projects, skills, and artifacts work together to create a more productive AI workspace. We’ll also walk through practical demos showing how these features can be used for real-world business, technical, and development scenarios.

You’ll learn:
- How to configure Claude settings and customize your experience
- How your profile and preferences can influence interactions
- How to use Projects to organize conversations, files, instructions, and context
- How Skills extend Claude with reusable capabilities and workflows
- How to create and work with Artifacts such as documents, code, diagrams, and interactive content
- How to combine Projects, Skills, and Artifacts into repeatable workflows
- Practical tips and best practices for using Claude more efficiently

## Who Should Attend
- Completed Claude 101? Take the next step beyond basic prompting and file usage.
- Developers, IT professionals, architects, and business users? Learn how to structure Claude for ongoing projects and more advanced workflows.
- Already using Claude regularly? Discover features that can make your work more organized, reusable, and productive.

No previous experience with Claude is required.
